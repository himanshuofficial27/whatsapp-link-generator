# WhatsApp link generator
Build a click-to-chat URL with an optional opening message. Open index.html directly in a browser. There are no dependencies or network requests while generating the link. Opening a generated link takes you to WhatsApp. The recipient must use WhatsApp and the visitor chooses whether to send the message.

Try a country code with spaces and confirm that the result contains only digits in its path. Try a message containing & and a new line, then inspect the decoded text. Enter a letter in the number and check the validation message.

The [full LoudFunnels tool](https://loudfunnels.com/free-tools/whatsapp-link-generator?utm_source=github&utm_medium=referral&utm_campaign=backlinks) also makes a QR code. Do not commit customer numbers or real conversations to examples.
